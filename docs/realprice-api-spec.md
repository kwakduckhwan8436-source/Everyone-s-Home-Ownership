# 실거래가 자동연동 사양 (B-2 준비 — 검증된 공식 사양, 추측 없음)

## 데이터 출처 (공공데이터포털 · 무료 · 이용범위 제한 없음)
- 국토교통부_아파트 매매 실거래가 자료 (dataset 15126469)
- 신청: data.go.kr → 활용신청(자동승인) → 마이페이지에서 인증키 확인(발급 후 사용까지 10~60분)

## 엔드포인트 · 파라미터
- 서비스명: `getRTMSDataSvcAptTrade` (상세: `getRTMSDataSvcAptTradeDev`)
- 요청 파라미터
  - `serviceKey` : 발급받은 인증키(URL 인코딩 주의)
  - `LAWD_CD`   : 법정동코드 앞 5자리 (예: 서울 종로구 11110) — 출처: 행정표준코드관리시스템(code.go.kr)
  - `DEAL_YMD`  : 계약년월 6자리 (예: 202608)
- 출력: XML (거래금액·전용면적·층·건축년도·법정동·아파트명·계약일 등)
- 데이터 범위: 2006년~현재

## 구현 시 주의 (정밀 처리)
1. **CORS**: 브라우저 직접 호출은 차단될 수 있음 → **서버 프록시 경유 필수**.
   - 이 프로젝트의 `ai-proxy`(FastAPI)에 `/realprice` 엔드포인트를 추가해 서버에서 호출·XML 파싱 후 JSON 반환.
2. **인증키**: 서버 환경변수(`MOLIT_SERVICE_KEY`)로 보관, 클라이언트 노출 금지.
3. **법정동코드 매핑**: 앱의 시도·구군 선택 → 법정동코드 5자리 매핑표 필요(code.go.kr 원본으로 구축, 추측 금지).
4. **표준(오프라인) 버전**: 네트워크·서버가 없으므로 자동연동 대신 공식 사이트 딥링크 유지(rt.molit.go.kr).
