# 모두의 내집마련 — 다음 검토 로드맵

이번에 반영된 것(계산·진단 7종) 이후, 다음 단계로 검토할 후보들입니다.
우선순위는 "초보자 체감 가치 × 구현 난이도"로 매겼습니다.

## A. 바로 얹기 좋은 것 (엔진 재사용, 저난이도)
- **월세 vs 전세 vs 매매 3종 비교**: 지금 전세 vs 매매에 월세를 추가(환산보증금·월세 총지출).
- **고정 vs 변동금리 비교**: 스트레스 테스트를 금리유형 선택으로 확장.
- **목표일 슬라이더 연동**: 계산·진단의 목표일을 바꾸면 분석 그래프도 같이 미리보기.
- **부담률 안전선 표시**: DSR 40%·주거비 30% 기준선을 그래프에 오버레이.

## B. 데이터 연동 (중난이도, 서버/키 필요 가능)
- **공공데이터포털 실거래가 API**: 주소 입력 → 그 단지 실제 실거래가 자동 반영(React 온라인판).
- **KB시세 기준 LTV 재계산 옵션**: 시세 vs KB시세 구분 입력.
- **지역 평균가·상승률 참고값**: 한국부동산원 통계(R-ONE) 인용.

## C. 신뢰·공유 (중난이도)
- **PDF 리포트 고도화**: 현재 window.print → 한 장 요약 레이아웃 전용 인쇄뷰.
- **계획 URL 공유**: 입력값을 URL 해시로 인코딩해 링크 공유(서버 없이).
- **정책 변경 알림 배지**: 스냅샷 날짜 대비 경과일 강조 + "최근 개정 확인" 링크.

## D. 개인화·행동 (중~고난이도)
- **월별 저축 리마인더**: (앱 설치형/PWA) 납입일 알림.
- **실적 그래프 고도화**: 계획선 vs 실제 저축선 오버레이(현재 실적 탭 확장).
- **시나리오 저장·비교 강화**: 계획 슬롯 A/B/C 나란히 비교(부분 구현됨).

## E. 접근성·품질 (지속)
- 화면낭독기(ARIA)·키보드 내비 점검, 색약 대비 팔레트 옵션.
- 모바일 1열 레이아웃 미세조정, 큰 글씨 모드.
- 카피 다듬기: 전문용어 → 쉬운 말 지속 교체.

## 법적·운영 (상업화 전 필수)
- 서비스 약관·개인정보처리방침 문서화(특히 AI 해설 사용 시 동의·전송 고지).
- 사업자 정보 표기(전자상거래법), 저작권/출처 표기 유지.
- 정책 수치 정기 업데이트 프로세스(분기 1회 스냅샷 검증).
