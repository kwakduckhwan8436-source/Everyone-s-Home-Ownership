# 모두의 내집마련 — 전체 완료 요약 (로드맵 A~E)

> 내집마련 **자금·시기 PLANNER**. 시세앱(호갱노노·아실·직방)을 보완해 "언제·어떻게 살 수 있는지"를 계획합니다.
> 핵심 엔진: **필요 자기자본 vs 가용 자기자본**을 240개월에 걸쳐 계산해 **교차점(도달 시점)**을 찾습니다.
> 검증 불변식: 데모 기본값 → **도달 2028-12 / 병목 소득(DSR)**. 모든 변경에서 유지 확인.

## A. 계산·진단 도구
- **A1 월세 vs 전세 vs 매수** — 전세보증금 기준 3종 월 주거비 비교. 전월세전환율은 **법정 상한 4.5%** 적용.
- **A2 고정 vs 변동금리** — 구조만 설명하고 고정금리 수치는 넣지 않음(추측 금지) → 금융상품 한눈에 링크.
- **A3 목표일 슬라이더** — 6~120개월 슬라이더로 목표일 조정, 필요 월 저축 즉시 재계산.
- **A4 부담률 안전선** — 게이지에 **DSR 40%(규제)** · **30%(가이드)** 기준선 표시.

## B. 데이터 연동 (실거래가·시세)
- **B1 공식 딥링크** — 국토부 실거래가 공개시스템·KB부동산·한국부동산원(실제 데이터, 키 불필요).
- **B2 백엔드 `/realprice`** — 공공데이터포털 **무료** 아파트 실거래가 API 서버측 호출(CORS 회피). py_compile 통과.
- **B3 `/realprice_avg`** — 최근 3개월(신고지연 감안 지난달부터) 평균 → 목표가 자동 제안.
- **법정동코드** — 서울 25개 자치구 검증값 포함(행안부 교차확인). 그 외는 code.go.kr.

## C. 신뢰·공유
- **C1 PDF 리포트** — 인쇄 상단에 핵심 요약(도달·목표가·월저축·병목) 자동 표기, 배경 흰색, 분석 강제표시.
- **C2 URL 공유** — 입력값을 해시(#p=)로 인코딩/복원. 서버 없이 링크 공유.
- **C3 정책 배지** — 스냅샷 날짜 표시, 90일 경과 시 경고색, 클릭 시 근거 탭 이동.

## D. 개인화·행동
- **D1 저축 리마인더(.ics)** — 매월 반복 캘린더 일정 내보내기(오프라인 동작). 푸시 대신 캘린더 앱 활용.
- **D2 계획 vs 실제 그래프** — 계획 순자산선(점선) + 실제선(금색) 오버레이 + 범례 + 앞섬/뒤처짐 피드백.
- **D3 계획 슬롯 A/B/C** — 저장 계획(또는 현재값) 3안을 나란히 비교, 가장 빠른 안 강조.

## E. 정교화
- **E1 가정 투명화** — 계산에 쓰인 값을 **법정·규제 / 공식 / 가정 / 입력** 4그룹으로 배지와 함께 전부 공개.
- **E2 복합 스트레스** — 금리+2%p·집값 상승0%·저축10%↓ 및 셋 동시(복합 악재)를 **엔진으로 재계산**해 도달 시점 변화 표시.
- **E3 접근성** — tablist/tab/tabpanel·키보드 화살표 탐색·입력 aria-label·도움말 aria·aria-live·포커스 표시·WCAG 대비·모션 축소.
- **E4 성능** — 입력 디바운스 110ms·활성 탭만 렌더·탭 화살표 rAF 스로틀·passive 리스너.

## UI/UX
- 좌/우 패널 구성, **메뉴(탭)를 우측 패널 상단**에 배치 + **좌우 화살표**로 스크롤.
- 좌측 입력 **초보자 개편**(카드 평탄화·단일 열·친근한 섹션 제목).
- **도시 풍경 배경**: 사실감 아파트(발코니·측면 음영·옥탑·필로티·불 켜진 창) + 집·숲·강·다리·보트·도로·자동차·전철 + **하늘의 해·구름·새**.
- 반응형(핸드폰) + **모바일 배경 성능 옵션**(≤760px에서 고정배경 해제).

## 검증된 공식 데이터 (추측 없음)
- **전월세전환율 상한** = min(연 10%, 기준금리+2%p) = **4.5%** (한국은행 기준금리 2.5%, 주택임대차보호법 §7의2·시행령 §9).
- **DSR 40%**(은행권 규제) · **주거비 30%**(가이드) · **중개보수 요율**·**취득세**·**LTV**(규제지역 2025.10.16).
- **실거래가 API 무료** — 공공데이터포털 국토교통부 아파트 매매 실거래가(dataset 15126469), 일 1,000회(개발계정 최대 10,000).
- **서울 25구 법정동코드** — 행안부 시도시군구코드·2026-07-01 시군구 행정코드 교차확인.
- 공시가격 반영률 69%(보유세 근사) · 전세 기회수익률 3% · 브릿지 5.5%·최대6개월 · 중도상환 1.2% → 전부 '가정'으로 명시.

## 사용법 요약
- **표준 HTML**: 파일 더블클릭(오프라인). 실거래가 자동조회 대신 공식 링크 사용.
- **React HTML**: 온라인에서 열기(CDN). 실거래가 자동조회는 ai-proxy 백엔드 필요.
- **패키지 zip**: `react-project`(npm run build) + `ai-proxy`(uvicorn, 무료 인증키 MOLIT_SERVICE_KEY) + `docs`.

## 남은 확인 / 후속 후보
- 실거래가 API는 **본인 무료 인증키 + 백엔드 실행**으로 실제 호출 검증 필요(개발 환경 네트워크 차단으로 여기선 미검증).
- React 전체 타입체크는 node_modules 환경(`npm run build`)에서 최종 확인.
- 후속 아이디어: 배경 낮/노을 토글, 전국 법정동코드 매핑 확장, 실거래가 지역 비교 강화, 시나리오 저장 공유.

- **B6 목표 달성 확률**: 집값 상승률 ±1.5%p·금리 ±0.7%p(정규분포) 400회 몬테카를로 → 240개월 내 도달 확률 + 도달 시기 P25/P50/P75 + 연도별 분포. 예측이 아닌 가정 기반 추정(투명 표기). 결정론 도달과 P50 일치 검증.
